# 日报说明

- 每个 AI 每个工作日结束时写一份日报，模板见 [TEMPLATE.md](TEMPLATE.md)。
- 路径：`daily-reports/YYYY-MM-DD/<role>.md`，例如 `daily-reports/2026-10-30/ios-developer.md`。
- 角色文件名：`chief-engineer`、`ios-developer`、`algorithm-engineer`、`vision-engineer`、`backend-puzzlebank-engineer`、`test-engineer`、`code-reviewer`。一人兼多个角色时，每个角色各写一份，或合写一份并在标题注明全部角色。
- Ari 汇总后写 `daily-reports/YYYY-MM-DD/summary.md`，模板见 [SUMMARY_TEMPLATE.md](SUMMARY_TEMPLATE.md)。
- 日报要简短、具体，链接到 PR / 任务卡。
