# 0002. 最低系统版本为 iOS 26

## 状态

已接受（P0）

## 背景

P0 需要给新工程定一个最低 iOS 版本。写这份记录时（2026-10），最新系统是 iOS 27（2026-09 发布）。

## 决定

App 和 `SudokuEngine` 的最低 iOS 版本是 **iOS 26.0**。

- 工程设置：`IPHONEOS_DEPLOYMENT_TARGET = 26.0`
- 引擎包：`.iOS(.v26)`
- 引擎包同时声明 `.macOS(.v15)`，只为了在 Mac 上跑 `swift test`，不是产品目标

## 理由

- 应用还没有存量用户，不必为了更老的系统把最低版本压到 iOS 18。
- 也不锁到刚发布的 iOS 27，避免把尚未升级的设备挡在外面。
- P0 没有必须使用 iOS 27 API 的功能。
- GitHub Actions 的 `macos-26` 镜像带 Xcode 26，可以按这个最低版本构建，并在 iOS 26 模拟器上跑测试。

## 后果

- CI 使用 `macos-26`。不要改成更老的 runner，否则没有 iOS 26 SDK。
- 这些 job 共用一条队列，同一时刻只申请一台 `macos-26`。并行申请多台时，排不到机器的 job 会在大约 15 分钟后被取消。
- 以后如果要使用 iOS 27 专有 API，再评估是否抬高最低版本。
