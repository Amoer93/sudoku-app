# 审查清单

意见分成两类：

- **必须改**：不改不能合并。
- **建议**：可以跟进，不挡住这次合并。

## 必须改

- 逻辑是否正确，错误是否处理或明确上抛。
- 是否有强制解包（测试除外）。
- 引擎是否保持无 UI 依赖；界面是否复制了算法。
- 有没有未经 Ari 同意的第三方运行时依赖。
- 新增行为有没有测试；修 bug 是否先有能复现的测试。
- 接口变了是否先改了文档。
- SwiftLint 是否零警告，CI 是否通过。
- 密钥、证书、用户照片是否进了仓库。

## 建议

- 有没有更直白的写法。
- 函数是否过长；重复是否已经出现第三次，才值得提取。
- 命名是否能直接看懂。

## 流程

- 作者不能审查自己的代码。
- 合并需要 CI 全绿、一位非作者审查通过、Ari 确认。
