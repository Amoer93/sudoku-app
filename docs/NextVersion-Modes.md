# 下一版模式规划（教学 / 练习 / 挑战）

> **状态：规划稿，未开工。**  
> 来源：Amoer 电话口述（墨尔本时间约 2026-11-06）。  
> 优先级：当前优先 App Store 上架准备；本文件只存方向，不实现代码。

## 目标

在现有对局能力之上，面向中小学生形成「边学边玩 + 技法反馈 + 友好竞赛」三条路径，为上架后的留存和后续变现打基础。

---

## 1. 教学 + 游玩一体

- 提供独立的 **「教学」模式**（与普通对局并排入口，不混在同一套默认流程里）。
- 教学内容采用公信力高、成体系、成规模的网上教学法（具体教材体系待定）。
- **Ari 负责拆课**：把体系拆成一节一节的课。
- 每一节课建议包含：
  - 文字讲解
  - GIF 图演示
  - 可能的实盘玩法（边学边玩）
- 用户在教学路径里一边学技法，一边在实盘上练习。

## 2. 操作归类与技法统计

- 用户下棋时，**每一步操作归类**到某套教法中的具体技法（例如扫描 / 骑行、反向排除等；具体技法表随选定教材走）。
- 做完一题后给出 **技法清单报告**：类似游戏里的连击统计，但统计的是解题技法（用了哪些、各用了多少次）。
- 用途：学习反馈、挑战评分、后续课程推荐。

## 3. 挑战模式

- 目标：尽量用 **简单技法** 打满题目，尽量少用复杂技法（计算量小、更贴近「干净解法」）。
- 可加 **排行榜**，例如：
  - 速度题：谁用最快速度解出
  - 技法简易度：谁用更简单的技法组合解出
- **挑战模式不允许提示**（含自动提示 / 自动解题类能力关闭）。

## 4. 未来三种模式

| 模式 | 要点 |
|---|---|
| 教学 | 成体系课程 + 讲解 / GIF / 实盘 |
| 练习 | 日常对局与技法统计（是否等同现有题库对局待定） |
| 挑战 | 无提示；按速度和/或技法简易度排名，形成互相比较 |

挑战模式通过速度榜与算法简易度榜制造比较兴趣。

## 后续版本：AI 教练接入（在「教学 / 练习 / 挑战」之后）

> **排期说明：本节属于三模式版本之后的下一版，不纳入当前「教学 / 练习 / 挑战」实现范围。**

### 1. 用户自管 API Key
- App 内提供 API Key 入口，由用户自行填写与管理。
- 支持用户自选供应商，例如 Claude Code、Codex、DeepSeek、Kimi，或其他用户自选的提供方。
- **账号与账单由用户自己向供应商付费管理；App 不代收、不处理支付。**

### 2. AI 是教练，不是给答案的人
- 接通后，AI 扮演教练：提示技法方向，不直接给出完整解法。
- 与挑战模式「不允许提示」一致：挑战局里仍不开放给答案式帮助；教练式点拨主要落在练习等允许轻提示的场景。

### 3. 出题侧预计算技法成本
- 生成题目时，对每道题预计算技法成本。
- 同一题往往有多条解法路径，需覆盖多种可能路径上的技法代价，供后续推荐与挑战评分使用。

### 4. 按技法使用频率推荐练习
- 根据用户技法使用统计：
  - 常用技法 → 推荐同类变体题，加深熟练度；
  - 很少用的技法 → 推荐该技法的入门级题目，补短板。

### 5. 练习模式轻量提示按钮
- 练习模式提供轻量「提示」按钮。
- 分析当前盘面，用两三句话给出极简点拨（方向级，不铺开整盘答案）。

### 6. 本地解题历史 +「推荐」按钮
- 本地保存解题历史。
- 「推荐」：把本地已解题目相关摘要发给 AI，分析哪些技法用得最少、哪些需要加强，返回**技法类型**建议。
- **从题库筛选 / 排序 / 选题由本地代码完成，不是模型的职责。**

### 7. 紧凑盘面编码，控制 Token
- 调 API 时用紧凑编码表示棋盘，控制上下文体积。
- 一盘数独可压缩到大约几百 token 量级。
